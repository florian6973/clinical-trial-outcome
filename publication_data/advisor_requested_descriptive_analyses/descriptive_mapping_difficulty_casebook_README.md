# Descriptive mapping-difficulty casebook

This sample is **not formal validation and is not an error-rate estimate**. The
locked mapping contains production assignments but no paired gold labels,
model predictions, confidence scores, or adjudicated error labels. Cases are
selected deterministically from transparent lexical and multiplicity strata to
support manual review and manuscript examples. A formal error analysis must be
run on the held-out annotated set with predictions frozen before adjudication.
